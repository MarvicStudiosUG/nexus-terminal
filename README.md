# Nexus Terminal Pro

A professional command-line interface in your browser with real-time APIs, encrypted vault, virtual file system, and more.

## Features

- **40+ Commands** – Weather, crypto, news, IP, DNS, currency, GitHub, SpaceX, quotes, sports, game deals, Reddit, stocks, translation, and more.
- **Encrypted Vault** – Store sensitive notes securely with AES-GCM encryption (Web Crypto API).
- **Virtual File System** – Create, read, delete, and search files. Drag and drop to upload.
- **Command Aliases** – Create custom shortcuts for any command.
- **Themes** – Cyber Neon, Deep Ocean, Monochrome, Matrix, Sunset.
- **Autocomplete** – Tab completion for commands and aliases.
- **History Search** – Ctrl+R to search command history.
- **API Caching** – Reduces rate limits and improves performance.
- **Responsive** – Works on desktop and mobile.

## Usage

Type `help` to see all available commands. Click any command in the help output to auto-fill it.
